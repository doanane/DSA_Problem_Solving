## Question 1 — Three Consecutive Elements Greater Than Threshold

**Problem.**
Given an integer array `numbers` and an integer `threshold`, find the first index `i` such that
`numbers[i]`, `numbers[i+1]`, and `numbers[i+2]` are all greater than `threshold`.
If no such index exists, return `-2`.

**Input.**
- `numbers`: list of integers (length >= 0)
- `threshold`: integer

**Output.**
- An integer index `i` (0-based) of the first valid triple, or `-2` if none exists.

**Example.**
Input: `numbers = [0, 1, 4, 5, 7, 9]`, `threshold = 1`  
Output: `1`  (because 1→ elements `[1,4,5]` all > 1 and 1 is the first such index)

**Constraints & Notes.**
- Acceptable time complexity: O(n^2) or better (O(n) is possible by scanning once).
- Edge cases: if `numbers.length < 3`, return `-2`.

**Hint.**
- Slide a window of size 3 across the array and check the condition.

## Question 2 — Skeletons Matching Word (Dot Placeholder)

**Problem.**
You are given a target string `word` (lowercase letters) and a list of `skeletons`. Every skeleton has the same length as `word`.
A skeleton can form `word` if every `.` character in the skeleton can be replaced by characters (selected from other positions in the same skeleton) so that the resulting string equals `word`.

Return a list of skeletons that can form `word`, keeping the original order. Return an empty list if none match. Duplicates in `skeletons` are allowed and should be preserved.

**Input.**
- `word`: string of lowercase letters
- `skeletons`: list of strings (each same length as `word`)

**Output.**
- List of skeleton strings that can form `word`.

**Example.**
Input: `word = "hello"`, `skeletons = ["hello", "hero", "+n1-", "hello"]`  
Output: `["hello", "hello"]`

**Complexity (acceptable).**
- A solution with time complexity O(skeletons.length * word.length^2) is acceptable.

**Notes & approach.**
- For each skeleton, check if every non-dot position matches `word`. For dots, ensure they can be substituted from characters available in the skeleton at other positions (implementation detail depends on exact rules — if dots can be any letter independent of the skeleton, the check is simpler).

## Question 3 — Skeletons Matching Word (Dash Placeholder)

**Problem.**
Same as Question 2, but skeletons may use `-` (dash) as a placeholder instead of, or in addition to, `.`. Dashes are treated like dots for the matching rule described in Question 2.

**Example.**
Input: `word = "hello"`, `skeletons = ["hello", "hero", "-q1", "hello"]`  
Output: `["hello", "hello"]`

**Explanation (from example).**
- `"hello"` → direct match.  
- `"hero"` → fails because placeholders (if any) cannot match both `l` characters in `hello` under the skeleton's constraints.  
- `"-q1"` → fails due to mismatched placeholders/characters.  
- `"hello"` → matches directly.

**Notes.**
- Clarify placeholder semantics before implementing: whether each placeholder is free to map to any letter, or must map only to characters present somewhere in the same skeleton.

## Question 4 — Point of Maximum Overlap from Lamps

**Problem.**
You are given a list `lamps` where each lamp is described by `[position, radius]`. Each lamp covers the interval `[position - radius, position + radius]` on the number line.

Find the coordinate of a point that is covered by the maximum number of lamps. If multiple coordinates have the same maximum coverage, return the smallest such coordinate.

**Input.**
- `lamps`: list of pairs `[position, radius]` where `position` is an integer and `radius` is a non-negative number (integer or float).

**Output.**
- A number (integer or float) representing the smallest coordinate with maximum coverage.

**Example (illustrative).**
If `lamps = [[1, 3], [2, 3], [5, 2]]`, the coverage intervals are `[-2,4]`, `[-1,5]`, and `[3,7]`. The point `3` is covered by all three lamps, so return `3`.

**Hints & approach.**
- Sweep line: treat each interval start as `+1` and each interval end as `-1`, sort events, and scan to maintain current overlap count. Track the coordinate(s) where the overlap is maximum.
- If intervals are continuous floats, be careful with open/closed endpoints; the problem as stated treats intervals as closed `[a, b]`.
